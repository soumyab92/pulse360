# PULSE360 — Project Overview

> **Built & engineered collaboratively using Antigravity** — Google DeepMind's advanced agentic AI coding assistant.

A high-performance, real-time 360° internet diagnostic platform and grounded AI network operator.

---

## 🛠️ Tech Stack Used

### 1. Frontend Architecture
- **Vanilla ES Modules & JavaScript**: Pure browser-native ES6+ modules (`type="module"`) with zero runtime bundler overhead.
- **Tailwind CSS**: Modern dark-mode UI styling with custom neon telemetry palette (`#00f0ff` cyan, `#00f7a5` neon green, `#FF4B1F` accent).
- **HTML5 2D Canvas & WebGL**:
  - Custom 360° SVG/Canvas gauge cluster with dynamic needle acceleration.
  - Interactive 3D WebGL Hyperspace Particle Tunnel driven live by network throughput.
  - Multi-dimensional Network DNA Radar chart rendered on interactive canvas.
- **Client-Side RAG & Vector Engine**:
  - **Web Workers**: Background embedding generation without blocking UI threads.
  - **IndexedDB**: Persistent browser-side vector storage for offline-capable knowledge retrieval.
- **Web Audio API & Haptics**: Procedural synthesizers for audio feedback during test phases and vibration patterns on mobile devices.

### 2. Backend & Deployment
- **Zero-Dependency Native Node.js 22**: Built exclusively with Node.js standard library (`http`, `fs`, `path`, `zlib`, `url`).
- **Serverless API Architecture**: Fully compatible with Vercel Serverless Functions (`api/health.js`, `api/knowledge.js`, `api/pulse-llm.js`).
- **SSE (Server-Sent Events)**: Real-time chunked streaming for AI typewriter responses.
- **Edge CDN Optimization**: Pre-configured for global Edge CDN static asset delivery and instant gzip compression.

### 3. Network Telemetry Engine
- **Cloudflare Anycast Edge Network**: High-throughput bidirectional chunk streams (`/__down`, `/__up`, `/cdn-cgi/trace`).
- **RFC 3550 Standard Jitter & Bufferbloat Algorithm**: Measures loaded latency under full bidirectional saturation.
- **DoH (DNS over HTTPS) Benchmark**: Concurrent probing against Cloudflare (1.1.1.1), Google (8.8.8.8), Quad9 (9.9.9.9), and OpenDNS.

## ⚡ What This App Can Do (In Short)

1. **Real-Time Speed Testing**: Measures accurate download and upload speeds with live 100ms gauge updates using global Anycast endpoints.
2. **Bufferbloat & SQM Grade (A+ to F)**: Tests loaded latency under network saturation to identify lag spikes during gaming or video calls.
3. **Network DNA Radar**: Generates a 6-axis visual fingerprint score (Speed, Stability, Latency, Upload, Bufferbloat, DNS).
4. **60-Second Stability Test**: Continuous high-frequency sampling that charts standard deviation, jitter spikes, and packet drops over time.
5. **DNS Resolver Benchmark**: Ranks top global DNS resolvers by response speed to help optimize routing.
6. **Real-Life Workload Verdicts**: Gives instant pass/fail ratings for Competitive Gaming, 4K HDR Streaming, and Zoom/Teams Calls.
7. **Ask PULSE (AI Operator)**:
   - Compact bottom-right corner popup assistant.
   - **Agentic Test Dispatch**: Automatically executes speed tests, stability modes, or DNS audits upon command.
   - **Typo Tolerance**: Fuzzy matches misspelled queries using Damerau-Levenshtein distance (e.g. `donwload`, `pnig`, `buffrblot`).
   - **Laser-Focused Answers**: Gives direct, concise answers first with interactive follow-up chips and zero clutter.
8. **Exportable Network Report**: One-click PNG canvas export of your Network DNA report card for sharing or ISP dispute documentation.
